Implementation blueprint · desktop pane · commit b3a06e20

Interrupt is a hand brake. Undo lives on the request row.

This page is the UI that shipped, not a mock-up of it: every pane below is built from the same crusorai-* class names the renderer emits, and every rule in the pane is copied from desktop/vscode/src/vs/workbench/contrib/crusorai/browser/media/crusorAI.css. Each frame names the function that builds it, the file and line it lives at, and the wire frame or field feeding it — so you can read the screen and the implementation in the same glance.

Token grammar every colour is a --vscode-* / --crusorai-* variable, no hex in the pane running = accent approval / landed = amber verified = green failed = red

00How to read this page

One screen, three layers

The pane has no template files: the renderer builds DOM nodes directly, so the DOM tree is the template. Reading a frame means reading three things at once — the node, the function that created it, and the frame that carries its data.

1 · The node

Built by element(tag, className, …children) in crusorAIRenderer.ts:289. Class names are the product's own vocabulary (crusorai-…), never utility soup — so a node in this page maps 1:1 to a rule in the stylesheet.

2 · The builder

One small function per surface: checkpointLine(), turnReceiptRow(), turnLedger(), inlineConfirm(), changedFilesCard(). They are pure (model, host) → HTMLElement, so both the Agent pane and the Crusor Manager paint the same markup from one code path.

3 · The data

CrusorAIRenderModel (the frame's fields) and CrusorAIRenderHost (the callbacks — cancel(), restoreCheckpoint(hash, file?), forkSession()). The wire supplies the model; the service implements the host.

Reading the annotations: numbered pins sit on the element they describe, and the numbered list beside each frame explains it. mono text is a real path, function name, or CSS selector you can grep. The pane glyphs are codicons in the app (codicon-* font); this page stands in unicode marks so it renders outside the editor — the geometry is identical.

◆Crusor Working
  1. The send slot becomes the brake: same 26 px cell, a solid square glyph instead of the arrow. One pull, no menu, no confirmation. Class crusorai-send-brake; while a pull is in flight the button is disabled, so a second pull is ignored rather than queued.
  2. The label is the honest one: Interrupt — stops now. The renderer never says "stop safely" — nothing is protected by waiting — and it never paints a pause glyph, which would imply resumable work.
  3. The stream label flips to Interrupted. the instant cancelRequested arrives — the frame drives it, not a timer.
  4. The hint bar names both verbs: Enter queues in the pane (steers in the Manager), Esc interrupts. The handler clicks the live brake button it finds in the DOM, so the hint can never advertise a key that does nothing.
