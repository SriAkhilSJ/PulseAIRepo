## What this proves

- The active default orchestrator no longer auto-approves: the dock appeared
  before implementation, and no file existed until the click arrived.
- The desktop `safety_reply` controls execution: clicking Allow once released
  the second gate and the mutations landed.
- The same run shows no evidence degradation banner after the fix.

## Not exercised in this smoke

- Desktop denial: proven at the bridge level (`probe-deny.txt`, turn cancelled,
  no files). A desktop deny click uses the same `safety_reply` path and queue
  resolution, but was not re-shot in Electron this round.
- Approval timeout/cancel through the dock: proven at the bridge level.
- Real provider/tool pipeline: this run uses deterministic orchestrator mock
  code generation; the approval, token and mutation-broker path is real.
