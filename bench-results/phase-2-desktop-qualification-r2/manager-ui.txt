The Manager restored the workspace group and one session row
(`workspace / session-0b74…`, `Finished`, `now`) from the durable store, then
showed an empty transcript (`transcriptRows: []`). For echo-runner sessions this
is expected: the seam writes the session row but no messages (see
`session-replay.txt`). A real durable transcript cannot be produced at this HEAD
because the graph path is blocked by the `history_shaper` import defect.
