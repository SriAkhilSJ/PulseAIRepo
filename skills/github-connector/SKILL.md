# GitHub Connector

**Triggers:** github, pr, pull request, issue, repo, git

**Instructions:**
- Prefer `gh` CLI if installed, else MCP `github` server
- Tools: search code, list PRs/issues, create PR, read file at commit
- Always show `repo/branch` in card, never commit without approval
- Fork UI: `Crusor Manager → Connectors → github: enabled · tools: [list_prs, create_pr]`
