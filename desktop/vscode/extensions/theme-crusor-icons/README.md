# Crusor File Icons

Default file icon theme for CrusorAI IDE.

The glyphs follow the VS Code Seti language (one flat mark per file type) with the colors approved for the rebrand: React is dark blue, Rust and Git are orange, Python uses the blue-and-yellow mark, and Markdown is `MD`.

Regenerate the PNG assets from the approved sheets with:

```bash
python branding/generate_file_icons.py
```
