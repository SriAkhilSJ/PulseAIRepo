## Conventions used in this folder

- **[V]** verified in code/git by me · **[R]** competitor research with a source · **[A]** assumption ·
  **[D]** repo documentation only.
- Every claim about product state pins to a commit. "Docs say" is never treated as "code does".
- No feature is marked complete without an executed test or a captured run.
